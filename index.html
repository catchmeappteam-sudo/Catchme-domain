Features Deep Dive

캐치미 핵심 기능 상세 분석

모임 조율과 장소 선정 과정에서 발생하는 모든 마찰(Friction)을 제거합니다.

1. 자동 가용성 매칭 알고리즘

"언제 다 같이 볼 수 있어?"라는 질문에 일일이 답할 필요가 없습니다. 개인 캘린더나 빈 시간을 가볍게 등록하면, 시스템이 겹치는 최적의 공백 타임을 실시간 순위별로 산출해 줍니다.

2. 중간 지점 최적화 & 커스텀 맵

참가자들의 출발 위치를 기반으로 모두에게 공평하고 이동 시간이 최소화되는 중간 지점을 추천합니다. 또한 자체 커스텀 맵 레이어를 통해 복잡한 지도 로딩 지연을 해결했습니다.

3. 실시간 그룹 상태 동기화

참가 여부 변경, 장소 투표 결과, 지각 여부 등을 웹소켓 및 실시간 상태 관리를 통해 지연 없이 모든 멤버의 화면에 동기화합니다.
